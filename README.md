# dating_site

Веб-сайт знакомств на **Flask**. Главная особенность — подбор пар не по случайному принципу, а по **психологической совместимости типов личности (MBTI)**: при регистрации пользователь проходит короткий тест, и сайт ранжирует анкеты других людей по таблице совместимости.

---

## Возможности

- **Регистрация** с анкетой: имя, возраст, город, «о себе», аватар.
- **Тест личности** сразу после регистрации — 4 вопроса, определяющие тип по MBTI (E/I, S/N, T/F, J/P).
- **Авторизация** по почте и паролю (пароли хранятся в виде хэша).
- **Главная страница** показывает подобранные анкеты, отсортированные по проценту совместимости.
- **Редактирование своей анкеты**, включая замену аватара (картинка автоматически сжимается до 300×300).
- **Лайки и взаимные симпатии** — можно «откликнуться» на анкету; при взаимном отклике образуется пара (match).
- **Раздел «Кому я понравился»** и **список переписок**.
- **Чат в реальном времени** между совпавшими пользователями (через WebSocket).
- **REST API** для получения списка пользователей и результатов теста.

## Модель данных

- **users** — анкета: `id`, `name`, `age`, `city`, `about`, `img`, `email`, `hashed_password`, `modified_date`.
- **pr_test** — ответы на тест личности: `ID`, `v1`, `v2`, `v3`, `v4` (буквы MBTI).
- **responses** — связи симпатий: кто на кого откликнулся (`id_person_responses`), кто откликнулся на пользователя (`id_responses_to_person`), взаимные совпадения (`vz_responses`).
- **rooms** — комнаты чата (`id_room` в формате `больший_id-меньший_id`).
- **messages** — сообщения чата: `id_first`, `id_second`, `message`.

## Как работает подбор пар

1. Пользователь проходит тест из 4 вопросов → получает тип MBTI (например, `INTJ`).
2. Тип сохраняется в таблицу `pr_test`.
3. Функция `sovmest()` в `bibl.py` сравнивает тип пользователя с типами всех остальных по словарю `sovm`, где каждой паре типов сопоставлен процент совместимости (от 1 до 99).
4. Анкеты сортируются по убыванию совместимости и выводятся на главной странице.

## Установка и запуск

Требуется **Python 3**.

```bash
# 1. Клонировать репозиторий
git clone https://github.com/KYSTIK473/dating_site.git
cd dating_site

# 2. Создать виртуальное окружение
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить
python main.py
```

После запуска сайт доступен по адресу **http://127.0.0.1:5000/**.

> **Тестовый аккаунт:** почта `user@com.ru`, пароль `123`.

## Замечания

- Файл `requirements.txt` содержит «замороженное» окружение целиком и включает много лишних библиотек (PyQt5, pygame, pyinstaller и др.), не используемых проектом. Для работы сайта реально нужны: `Flask`, `Flask-Login`, `Flask-WTF`, `WTForms`, `Flask-SQLAlchemy`, `SQLAlchemy`, `SQLAlchemy-serializer`, `Flask-SocketIO`, `Flask-RESTful`, `Pillow`, `eventlet`. Часть зависимостей (`pywin32`, `pypiwin32`) предназначена только для Windows.
- Путь к базе данных в коде указан в нескольких местах по-разному (`db/data.db`, `db/jobs.db`, `data.db`) — при запуске стоит убедиться, что используется один и тот же файл.
- `SECRET_KEY` задан прямо в коде — для боевого окружения его нужно вынести в переменные окружения.
- Это учебный проект; при использовании в продакшене рекомендуется ревизия безопасности (в частности, SQL-запросы в `bibl.py` и `news_api.py` собираются конкатенацией строк).
